# Netflix Data Visualization & EDA

Exploratory Data Analysis (EDA) and data visualization of the Netflix titles dataset using Python.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Regex

## Work Covered
- Loaded and inspected the Netflix titles dataset
- Explored rows, columns, data types, and missing values
- Handled missing values in director, cast, country, rating, date added, and duration-derived fields
- Extracted duration values and duration type
- Compared Movies vs TV Shows
- Analyzed release-year distribution
- Visualized content percentage
- Analyzed content trends over release years
- Compared release years by content type
- Performed correlation analysis using an encoded content type

## Visualizations
- Bar chart
- Histogram
- Pie chart
- Line plot
- Box plot
- Correlation heatmap

## File
- `Netflix_EDA.ipynb` — complete EDA notebook

## Dataset
The notebook expects a file named `netflix_titles.csv` in the working directory. The dataset file is not included here because it was not provided with the notebook.

## How to Run
Open `Netflix_EDA.ipynb` in Jupyter Notebook or Google Colab, place `netflix_titles.csv` in the same working directory, and run the cells in order.
